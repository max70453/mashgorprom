# Изменения темы оформления проекта МАШГОРПРОМ

## Дата изменений
9 февраля 2026

## Описание
Проект успешно преобразован из темной темы в светлую тему оформления.

## Основные изменения

### 1. CSS переменные (css/home.css)
Обновлены основные цветовые переменные:

**Было (темная тема):**
- `--bg: #0c0c0c` (черный фон)
- `--bg-elevated: #141414` (темно-серый)
- `--bg-card: #1a1a1a` (темно-серый для карточек)
- `--text: #f5f5f5` (светлый текст)
- `--text-muted: #a3a3a3` (приглушенный светлый)
- `--border: rgba(255, 255, 255, 0.08)` (светлые границы)

**Стало (светлая тема):**
- `--bg: #ffffff` (белый фон)
- `--bg-elevated: #f8f9fa` (светло-серый)
- `--bg-card: #ffffff` (белый для карточек)
- `--text: #1a1a1a` (темный текст)
- `--text-muted: #6c757d` (приглушенный темный)
- `--border: rgba(0, 0, 0, 0.1)` (темные границы)

### 2. Обновленные компоненты

#### Header (Шапка сайта)
- Фон изменен с полупрозрачного черного на полупрозрачный белый
- Добавлены тени для лучшей видимости
- Цвет текста кнопок навигации адаптирован

#### Hero (Главный баннер)
- Градиент оверлея изменен с черного на белый
- Кнопки навигации слайдера обновлены
- Индикаторы пагинации адаптированы

#### Кнопки
- `.btn-primary`: цвет текста изменен с черного на темно-серый
- `.btn-light`: фон изменен с белого на темно-серый, текст на белый

#### Карточки и оверлеи
- Все градиенты оверлеев изменены с черных на белые
- Тени смягчены для светлой темы
- Границы карточек адаптированы

### 3. Новые стили

Добавлены стили для страницы `industry-construction.html`:
- `.industry-solutions` - основная секция
- `.industry-layout` - сетка с боковой панелью
- `.showcase-section` - витрина продуктов
- `.process-section` - временная шкала процессов
- `.services-showcase` - карточки услуг

Добавлен утилитарный класс:
- `.container` - контейнер с максимальной шириной

### 4. Измененные файлы

1. **css/home.css** - основной файл стилей (полностью обновлен)
2. **css/style.css** - обновлена секция контактов

### 5. Адаптивность

Все изменения полностью адаптивны и работают на всех устройствах:
- Desktop (1024px+)
- Tablet (768px - 1024px)
- Mobile (до 768px)

## Дополнительные изменения

### Инверсия логотипа
Применен фильтр `filter: invert(1)` ко всем логотипам в проекте:
- `.logo img` - логотип в шапке сайта
- `.footer-logo` - логотип в подвале
- `#logo_img` - альтернативный селектор логотипа

Это обеспечивает правильное отображение логотипа на светлом фоне.
